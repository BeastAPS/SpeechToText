Mock AI Interview Coach

This is a full-stack application that provides a complete, AI-powered mock interview experience. The React frontend captures your voice using the browser's speech recognition, and a Python Flask backend uses the Google Gemini API to dynamically generate interview questions and provide detailed, quantitative feedback on your answers.

Features

Dynamic Interview: Begins by fetching 10 unique interview questions generated by the Gemini API.

Voice-to-Text: Uses the browser's built-in Web Speech API to transcribe your answers in real-time.

AI-Powered Feedback: Submits your answer to the Gemini API (gemini-2.5-flash) for analysis.

Quantitative Scores: Receives a 1-5 score for Relevance, Clarity, and Conciseness on every answer.

Detailed Report: Finishes with a summary page showing your overall average score and a per-question breakdown of your answers, scores, and AI feedback.

Tech Stack

Frontend: React, react-speech-recognition, Tailwind CSS

Backend: Python 3, Flask

API: Google Gemini (gemini-2.5-flash)

Setup Prerequisites

Node.js: (v16+) Required for the React frontend and npm.

Python: (3.8+) Required for the Flask backend.

Configuration

This project requires a Google Gemini API key to function.

Obtain a Gemini API Key from the Google AI Studio.

Navigate into the backend folder: cd flask-backend.

Create a file named .env (at the same level as app.py).

Add your API key to this file:

# flask-backend/.env
GEMINI_API_KEY="YOUR_API_KEY_HERE"


Installation

First, clone the repository and navigate into the main folder:

git clone [https://github.com/BeastAPS/SpeechToText.git](https://github.com/BeastAPS/SpeechToText.git)
cd SpeechToText


1. Backend (Flask)

These commands set up the Python virtual environment and install all required libraries.

# Navigate to the backend directory
cd flask-backend

# Create a virtual environment
python -m venv venv

# Activate the virtual environment
# Windows:
.\venv\Scripts\activate
# macOS/Linux:
source vVenv/bin/activate

# Install Python packages
pip install -r requirements.txt


2. Frontend (React)

These commands set up the Node environment and install the React dependencies.

# Navigate to the frontend directory (from the root)
cd react-frontend

# Install Node packages
npm install


Running the Application

You must run the backend and frontend simultaneously in two separate terminals.

Terminal 1: Start the Backend (Flask)

# Navigate to the backend directory
cd flask-backend

# Activate the virtual environment
source venv/bin/activate

# Run the Python server
python app.py


Your backend is now running at http://127.0.0.1:5000/.

Terminal 2: Start the Frontend (React)

# Navigate to the frontend directory
cd react-frontend

# Run the React development server
npm run dev


Your frontend is now running (usually at http://localhost:5173/) and is accessible in your browser.

Endpoints

The Flask server exposes the following API endpoints:

GET /interview

Generates and returns 10 unique interview questions.

Response: {"questions": ["question 1", "question 2", ... ]}

POST /get_feedback

Analyzes a user's answer to a specific question.

Request Body: {"question": "...", "answer": "..."}

Response: {"scores": {"relevance": <int>, "clarity": <int>, "conciseness": <int>}, "prose_feedback": "..."}
